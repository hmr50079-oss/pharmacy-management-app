# صيدلية الحي — متابعة المرضى

تطبيق بسيط وهادئ (عربي، RTL) لمتابعة مرضى صيدلية الحي وحالاتهم وجرعاتهم. يعمل مباشرة من المتصفح بدون تثبيت.

## التشغيل
1. افتح المجلد في مستكشف الملفات.
2. انقر نقراً مزدوجاً على **`index.html`**.

## المزايا
- **المرضى**: اسم، هاتف، تاريخ ميلاد، الحالة/المرض، مزمن أو مؤقت، ملاحظات الصيدلي + بحث وفلاتر (بحاجة لمتابعة / أمراض مزمنة).
- **الأدوية والجرعات**: اسم الدواء، الجرعة، المواعيد، تاريخ البدء، المدة، إيقاف/استئناف، زر **تسجيل جرعة اليوم** مع شريط تقدم.
- **سجل الزيارات**: التاريخ، الحالة (تحسّن / مستقر / يحتاج مراجعة)، ضغط وسكر اختياريين، ملاحظات المتابعة.
- **لوحة إحصائيات**: إجمالي المرضى، زيارات اليوم، أدوية نشطة، من يحتاجون متابعة (لم يزوروا منذ 14 يوم).
- **نسخة احتياطية**: زر تنزيل JSON + حفظ تلقائي في `localStorage`.
- **التصميم**: ألوان هادئة (بيج دافئ + أخضر مريمي + تيل ناعم)، متجاوب مع الجوال.

## الملفات
- `index.html` — الواجهة العربية
- `services.html` — صفحة خدماتنا (خدمات إضافية + تقييم التطبيق)
- `services.js` — منطق صفحة خدماتنا
- `styles.css` — الثيم الهادئ
- `app.js` — المنطق والتخزين المحلي
